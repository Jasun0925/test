## 1. Summary

**Purpose and Scope:**
Set up the foundational Spring Boot project structure including Maven build configuration, application configuration, Docker Compose for MySQL, the base entity class, the base exception class, the global exception handler, and the Flyway database migration. This story produces a runnable (but featureless) application that subsequent stories build upon.

**Actors/Triggers:**
- Developer initializing the project.

**Preconditions:**
- Java 25, Maven, and Docker are available in the development environment.

**Processing Flow:**
1. Create the Maven `pom.xml` with Spring Boot parent, required dependencies (Spring Web, Spring Data JPA, Flyway, MySQL connector, Lombok, spring-boot-starter-validation, spring-boot-starter-test).
2. Create the Spring Boot application entry point (`Application.java`).
3. Create `application.yml` with MySQL datasource, JPA/Hibernate, and Flyway configuration.
4. Create `docker-compose.yml` with a MySQL 8 service for local development.
5. Create `UUIDEntityBase` mapped superclass providing a UUID primary key field.
6. Create `ExceptionBase` abstract exception class accepting `HttpStatus` and `message`.
7. Create `GlobalExceptionHandler` (`@RestControllerAdvice`) to translate `ExceptionBase` subclasses and `MethodArgumentNotValidException` into JSON error responses.
8. Create Flyway migration `V1__create_greeting_table.sql` to create the `greeting` table.

**Success Behavior:**
- The application starts successfully, connects to MySQL, and Flyway applies the migration creating the `greeting` table.

**Error Behavior:**
- Application fails to start if MySQL is unreachable or Flyway migration fails.

**Dependencies:**
- None. This is the first story to be implemented.

### ExceptionBase

```java
public abstract class ExceptionBase extends RuntimeException {

    public ExceptionBase(HttpStatus status, String message);

    public HttpStatus getStatus();
}
```

| Aspect       | Detail                                                  |
| ------------ | ------------------------------------------------------- |
| Class        | `ExceptionBase`                                         |
| Purpose      | Base runtime exception for application-specific errors. |
| Input        | `HttpStatus status`, `String message`                   |
| Error Conds  | None — this is the error base itself.                   |

### GlobalExceptionHandler

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ExceptionBase.class)
    public ResponseEntity<Map<String, String>> handleExceptionBase(ExceptionBase ex);

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, String>> handleValidationException(MethodArgumentNotValidException ex);
}
```

| Method                    | Input                              | Return                          | HTTP Status | Purpose                                      |
| ------------------------- | ---------------------------------- | ------------------------------- | ----------- | --------------------------------------------- |
| handleExceptionBase       | `ExceptionBase ex`                 | `{"error": "<message>"}`       | From ex     | Translates application exceptions to JSON.    |
| handleValidationException | `MethodArgumentNotValidException`  | `{"error": "<description>"}`   | 400         | Translates Bean Validation failures to JSON.  |

## 4. Implementation Requirements

### Project Structure

- **pom.xml**: Spring Boot parent (latest stable), Java 25 source/target. Dependencies:
  - `spring-boot-starter-web`
  - `spring-boot-starter-data-jpa`
  - `spring-boot-starter-validation`
  - `flyway-core` and `flyway-mysql`
  - `mysql-connector-j` (runtime)
  - `lombok` (compile-only)
  - `spring-boot-starter-test` (test)

- **Application.java**: Standard `@SpringBootApplication` entry point.

- **application.yml**:
  - `spring.datasource.url`: MySQL JDBC URL (e.g., `jdbc:mysql://localhost:3306/greeting_db`)
  - `spring.datasource.username` / `password`: configurable
  - `spring.jpa.hibernate.ddl-auto`: `validate` (Flyway manages schema)
  - `spring.jpa.open-in-view`: `false`
  - `spring.flyway.enabled`: `true`

- **docker-compose.yml**: MySQL 8 service exposing port 3306, with environment variables for root password and database name.

### Base Entity

- `UUIDEntityBase` is a `@MappedSuperclass` with a `UUID id` field annotated `@Id`.
- The `id` is generated by the service (e.g., `UUID.randomUUID()`) in a `@PrePersist` callback or set explicitly before save.
- Stored as `VARCHAR(36)` in the database.

### Base Exception & Global Handler

- `ExceptionBase` extends `RuntimeException`, holds `HttpStatus` and `message`.
- `GlobalExceptionHandler` is annotated `@RestControllerAdvice`.
- `handleExceptionBase`: extracts status and message from `ExceptionBase`, returns `ResponseEntity` with `{"error": "<message>"}`.
- `handleValidationException`: extracts the first field error message from `MethodArgumentNotValidException`, returns HTTP 400 with `{"error": "<description>"}`.

### Flyway Migration

- File: `src/main/resources/db/migration/V1__create_greeting_table.sql`
- Content:
  ```sql
  CREATE TABLE greeting (
      id   VARCHAR(36)  NOT NULL,
      text VARCHAR(40)  NOT NULL,
      PRIMARY KEY (id)
  );
  ```

### Transactions

- No explicit transaction configuration in this story. Spring defaults apply.

### Security

- No authentication or authorization configured (BR-03, GO-03).

## 5. Acceptance Criteria

| ID   | Criterion                                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------------------- |
| AC-1 | The project compiles successfully with `mvn compile` using Java 25.                                               |
| AC-2 | `docker-compose up` starts a MySQL instance accessible on port 3306.                                              |
| AC-3 | The Spring Boot application starts without errors when MySQL is running.                                          |
| AC-4 | Flyway applies `V1__create_greeting_table.sql` on startup, creating the `greeting` table with columns `id VARCHAR(36) PK` and `text VARCHAR(40) NOT NULL`. |
| AC-5 | `UUIDEntityBase` provides a `UUID id` field usable as a JPA primary key.                                          |
| AC-6 | `ExceptionBase` can be subclassed with a specific `HttpStatus` and `message`.                                     |
| AC-7 | `GlobalExceptionHandler` returns `{"error": "<message>"}` with the correct HTTP status for any `ExceptionBase` subclass. |
| AC-8 | `GlobalExceptionHandler` returns HTTP 400 with `{"error": "<description>"}` for `MethodArgumentNotValidException`. |
| AC-9 | No authentication or security filters are configured; all endpoints are publicly accessible.                      |
